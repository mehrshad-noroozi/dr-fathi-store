# وب‌سایت دکتر فرهان فتحی

وب‌سایت استاتیک فارسی با چیدمان راست‌به‌چپ، طراحی واکنش‌گرا و انتشار از طریق GitHub Pages.

## انتشار
Workflow موجود در `.github/workflows/deploy.yml` با هر push به شاخه `main` سایت را روی GitHub Pages منتشر می‌کند.

## اطلاعات نیازمند تکمیل
- تصویر تأییدشده دکتر
- سوابق و حوزه فعالیت حرفه‌ای
- نام، تصویر و مشخصات واقعی محصولات
- راه‌های ارتباطی رسمی

هیچ ادعای درمانی یا اطلاعات تأییدنشده‌ای در نسخه اولیه درج نشده است.
